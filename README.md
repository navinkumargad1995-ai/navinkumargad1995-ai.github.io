# Navinkumar Gadparlawar — Portfolio

Personal portfolio site for Navinkumar Gadparlawar, Senior Angular Developer.

Live: https://navinkumargad1995-ai.github.io/

## Stack

Plain HTML, CSS and JavaScript — no build tooling, deployed directly via GitHub Pages.

## Structure

- `index.html` — page markup
- `assets/css/style.css` — styles (light/dark theme via CSS variables)
- `assets/js/script.js` — nav, theme toggle, scroll-spy, reveal animations, typed text
- `assets/resume/` — downloadable resume PDF

## Local development

Serve the folder with any static file server, e.g.:

```bash
python -m http.server 5500
```

Then open http://localhost:5500.
